# Dr. M Quamrul Hassan - Clinical Portfolio & Projects

Welcome to the GitHub repository for **Dr. M Quamrul Hassan, MBBS, FCPS**. 

This repository serves as both the hosting environment for my professional clinical website and the deployment server for my custom-built Paediatric Clinical Decision Support System (CDSS) tools.

## 🚀 Featured Clinical Tools

I have developed interactive digital tools to assist clinicians, registrars, and medical officers in the fast-paced hospital environment, translating static guidelines into dynamic, clinical workflows.

### 1. Paediatric ABX Guide (Progressive Web App)
A robust, offline-capable Progressive Web Application (PWA) that provides instant access to Paediatric Antimicrobial Guidelines. 
- **Dynamic Dosage Engine:** Features an intelligent calculator that detects the specific clinical pathway being viewed (e.g., Neonatal Sepsis, Meningitis) and instantly computes patient-specific `mg/kg` dosing regimens.
- **Offline First:** Built natively with vanilla web technologies to sit on iOS/Android home screens without requiring internet access on the ward.
- **Link:** [Launch Web App](https://mqhassan.github.io/abx-app/)

### 2. Paediatric Antimicrobial Ebook (Interactive CDSS)
A fully self-contained HTML-based clinical reference manual containing advanced pathways for bacterial, fungal, and viral infections in neonates and children.
- **Features:** Internal smooth-scroll navigation, dynamic sidebar indexing, and responsive design for viewing on desktops or tablets at the nurses' station.
- **Link:** [View Digital Ebook](https://mqhassan.github.io/Ebook/Paediatric_ABX_Guidelines.html)
